# Magento 2 Store Locator

A Magento 2 extension concept for managing store locations and presenting store information through a searchable frontend interface with an interactive map.

## Features

- Store management through the Magento Admin panel
- Store name, address, coordinates and contact details
- Configurable default map location and search radius
- Configurable default and active map marker images
- Store ratings, opening hours and service information
- Store cards and map information windows
- Sample data for development and demonstration

> Feature availability depends on the implementation and configuration in the current release.

## Requirements

- A compatible Magento Open Source or Adobe Commerce installation
- A PHP version supported by your Magento version
- Composer
- A database supported by your Magento version
- Google Maps API credentials if the implementation uses Google Maps

Exact compatibility must be verified against the module's `composer.json` and the Magento installation being tested.
