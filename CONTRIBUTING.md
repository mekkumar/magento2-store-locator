# Contributing

Contributions are welcome.

1. Open an issue to discuss a significant change.
2. Create a feature branch.
3. Keep changes focused and follow Magento coding conventions.
4. Add or update tests when applicable.
5. Verify the module on a supported Magento version.
6. Submit a pull request with a clear description and testing notes.

Do not include private credentials, proprietary client code, copyrighted assets without permission, production data or unrelated third-party code in contributions.
